# Configurable model routing

Product contract updated 23 October 2026:

- Core provides connections, models, effort variants and named routing profiles.
- Every authenticated user can configure personal profiles using permitted models.
- Custom Auto selects from an explicit pool; Full Auto tracks available models.
- A bounded classifier describes task/complexity; user rules and model roles select
  the executor. Exact assignments can choose any compatible model at any complexity.
- Everyday and Thorough provide editable starting points. No model brand is a
  hardcoded routing decision. No external key or cloud purchase is assumed.
- Manual, Default, chat/project bindings and stage-specific helper assignments
  share the existing resolver, credentials and budget.
- Trace records explain the configured choice and actual model/effort.
- No benchmark, judge, savings certificate or calibration is an activation gate.
- Local fixture checks cover decisions, native dispatch, permissions, settings,
  persistence, revisions, fallback, cancellation and limits.

The post-v0.7.0 economic qualification experiment has been retired. Its source and
records were preserved outside the product tree. Published results of that
experiment are not product requirements or claims. Historical SQL migrations and
read-compatible optional fields remain solely for existing configuration upgrades.
