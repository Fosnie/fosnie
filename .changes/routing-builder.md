# Personal routing profiles and model assignments

## changelog

Added Custom Auto and Full Auto profiles with editable presets, task and
complexity rules, model and effort assignments, preferences and pool restrictions.
Personal profiles and variants of shared models are available without personal
API keys.

## site

Build your own routing rules or start with the Everyday and Thorough presets.
Choose which models handle each kind of task and level of complexity in your
personal settings.

## detail

Profiles support shared connections, model variants, chat and project defaults,
cloning and import or export without credentials. Exact assignments can select
any compatible model for any level of complexity. Custom Auto uses a selected
pool, while Full Auto includes available variants as the catalogue grows.

Access controls, capability checks, local processing restrictions and usage
limits apply to every selection. An optional technical fallback permits one
alternate attempt before output is delivered.
